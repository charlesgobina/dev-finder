

# Dev-Finder

This project is a React application that allows users to search for GitHub usernames and retrieve user information. It was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

## Features

- Search for GitHub usernames
- Retrieve and display user information
- Light and dark mode support (Coming soon)

## Technologies Used

- JavaScript
- React
- npm
- Create React App

## How to Use

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Run the app using `npm start`.
4. Enter a GitHub username in the search bar and click "Search" to retrieve user information.
